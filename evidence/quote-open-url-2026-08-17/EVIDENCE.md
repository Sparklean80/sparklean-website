# Evidence — durable guided quote URL (2026-08-17)

Branch: `fix-contact-quote-url-2026-08-17`  
**Not deployed** until Tony approves.

## Problem fixed

On `/contact`, “Request Your Personalized Quote” used `href="/contact"` and relied on JavaScript intercepting the self-link. With JS delayed, blocked, or failed, the CTA was a dead loop. Ads visitors could click and never reach a real guided destination.

## Durable destination

`/contact?quote=1#quote-intake`

Optional preset (residential / city recurring CTAs):

`/contact?quote=1&preset=recurringResidential#quote-intake`

## Dual lead paths (separate — do not merge)

| Path | How to enter | Backend | Ads conversion |
|------|----------------|---------|----------------|
| Guided quote overlay | Durable URL above; opens on load / refresh / new tab / hash | `quote-submit` | Only after server returns `leadId` + `reportToken` |
| Simple contact form | Form on `/contact` (`#sparklean-contact-form`) | `contact-submit` | Same gate |

**Never** fire conversion from: loading `?quote=1`, opening intake, thank-you / `?sent=1`, or analytics-only events.

Attribution (`gclid` / `gbraid` / `wbraid`) persists via `sparklean-attribution.js` on both paths.

## What changed

- `js/quote-intake.js` — force-open on every page load for `?quote=1` / `#quote-intake` (refresh works); durable hrefs navigate for real; in-page open only when already on that URL
- `pages/contact.html` + `css/contact-page.css` — landmark `#quote-intake`, noscript fallback, durable CTAs, clearer dual-path copy, failure copy keeps form data + phone
- Service hubs + five city pages — quote CTAs → durable URL (homepage **not** modified)
- Tests: `npm run test:paid-intake`, `node scripts/verify-quote-open-url.mjs`
